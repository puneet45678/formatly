# Formatter Phase 1 (UI) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the complete formatter UI from the spec (layout B, rail, input/output panes, live output, errors, actions, routing, responsive). The formatting logic is a stub, so phase 2 only has to replace one module.

**Architecture:** Next.js App Router, built as a static export. Every format is a statically generated route `/[format]`. One layout-level React context holds the input for each format, so switching routes keeps the text. All formatting goes through one async function, `runFormatter()`. In phase 1 it echoes the input. In phase 2 it will call real formatters in a Web Worker, and nothing else will change.

**Tech Stack:** Next.js 16.4, React 19, TypeScript, Tailwind CSS 4, CodeMirror 6 via `@uiw/react-codemirror` 4.25, Vitest 5, React Testing Library 16, jsdom.

**Spec:** `docs/superpowers/specs/2026-11-04-formatter-design.md` (visual reference: `docs/superpowers/specs/layout-b-mockup.html`)

## Global Constraints

- Client-side only. `next.config.ts` sets `output: 'export'`. No route handlers, no server actions.
- Nothing the user pastes is ever written to storage or sent anywhere. Only `formatly:lastFormat` and `formatly:sqlDialect` go into `localStorage`.
- Every `localStorage` access goes through `src/lib/storage.ts`, which catches all errors.
- Formats, in rail order: JSON, YAML, Mermaid, XML, SQL, Markdown. Default format: JSON.
- Routes: `/json`, `/yaml`, `/mermaid`, `/xml`, `/sql`, `/markdown`. `/` goes to the last-used format, or JSON. Any other path shows a 404.
- Visual tokens are copied from the mockup: background `#0a0a0a`, page `#050505`, pane `rgba(17,17,17,.85)`, border `#232323`, rail border `#1a1a1a`, text `#ededed`, muted `#8f8f8f`, dim `#5c5c5c`. Grid lines `rgba(255,255,255,.055)`, 44px cells, radial fade `radial-gradient(ellipse at 50% 0%, transparent 30%, #0a0a0a 85%)`. Syntax colors: key `#7dd3fc`, string `#a7f3d0`, number/bool `#fcd34d`, punctuation `#6b7280`. OK `#4ade80`, error `#f87171`. Pane radius 10px. Fonts: Inter for the UI, JetBrains Mono for code, both via `next/font/google`.
- Dark theme only.
- Mobile breakpoint is Tailwind `md` (768px). Below it, the rail becomes a horizontal scrollable pill row and the panes stack.
- Placeholder product name: `formatly`.
- Code should be plain and readable over clever. The owner reviews it to learn frontend.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Rapid typing or pasting a large input:** the formatter runs only once after typing stops, never once per keystroke. (Task 5: `runs formatter once for a burst of changes`)
2. **Switching format while a result is still in flight:** a late result from the old format or the old input must never show up. (Task 5: `ignores a stale result`)
3. **`localStorage` throws** (private mode, blocked storage): the app still loads and works, and falls back to the defaults. (Task 3: `survives storage that throws`)
4. **A bad or tampered stored `lastFormat`** (e.g. `"csv"`): `/` goes to `/json`. (Task 4: `pickStartFormat ignores unknown values`)
5. **Clipboard denied or unavailable:** Copy shows "Copy failed" and nothing crashes. (Task 7: `shows Copy failed when clipboard rejects`)
